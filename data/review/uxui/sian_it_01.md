# 이탈리아어 유니버스 UX/UI 시안 it-01 — 만화책 읽기형(일본어앱 시안 02) + 이탈리아어 칸 2개 (2026-11-03, 세션 작성)

## 1. 콘셉트
기본 구조는 일본어앱 시안 02 그대로: **장면 컷이 주인공.** 고정 인물(Giulia·Chiara·Marco·Luca·학습자)이 로마의 하루를 만화처럼 이어 가고, 「모든 문장 듣기」는 컷이 넘어가듯 재생된다. 넓은 화면 = 왼쪽 레일 + 왼쪽 칸 대화 스크립트 + 오른쪽 큰 컷. 폰·좁은 칸 = 컷 위(약 44%) · 스크립트 아래.

이탈리아어만의 강점 두 가지를 칸 하나씩으로 드러낸다.
- **동사 활용**: 이탈리아어는 주어를 자주 빼고 동사 끝으로 "누가"를 말한다(parlo·parli·parla). 대사 속 동사를 누르면 6인칭 표가 펼쳐지고 지금 쓰인 인칭이 강조된다.
- **성·수 일치**: il/la/i/le 와 형용사 끝(-o/-a/-i/-e)이 명사에 맞춰 바뀐다. 캡션의 명사·형용사 밑에 작은 색 점(남성 단수·여성 단수·남성 복수·여성 복수)을 찍어 일치를 눈으로 보게 한다.

톤: 흰 바탕 · 남색 `#0A2540` 글자 · 포인트 올리브 그린 `#5E8A2A`(옅은 쪽 `#BDD698`) · 인디고 `#635BFF` 는 진행 막대·강조선만 · 선 `#E6EBF1` · 보조 글자 `#6B7C93` · 홈 상단 파스텔 메시. 8pt 그리드.

## 2. 그림 요청(다음 단계, 1장)
아이패드 가로 한 프레임(4:3, 태블릿 1대) — 편 화면 재생 중. 왼쪽 레일 · 왼쪽 칸 대화 스크립트(현재 턴 올리브 테두리) · 오른쪽 큰 점토풍 장면 컷(카페 바에서 Marco 가 에스프레소를 내밀고 학습자(여)가 받는 장면, 말풍선 하나) · 그 아래 캡션에 성·수 색 점 · 오른쪽 아래에 펼쳐진 동사 활용 작은 표 · 하단 컨트롤. 인물은 첨부 캐릭터 시트 그대로.

## 3. 레이아웃 (ASCII)

### 홈(배우기) — 아이패드 가로
```
┌────────┬───────────────────────────┬──────────────────────────────┐
│ 레일   │ 회화                        │ 오늘의 컷                      │
│ 배우기●│ ┌─서바이벌──────────────┐ │ ┌─장면 컷(주인공)──────────┐ │
│ 복습   │ │ 이야기 L1   0/5편      │ │ │ [점토풍 컷: 카페 바]       │ │
│ 탐색   │ └──────────────────────┘ │ │ 말풍선: Un caffè?          │ │
│ 나     │ 기초                       │ └──────────────────────────┘ │
│        │ · 소리 배우기(이중자음·강세)│ 이어서 읽기 · 커버율 0%       │
│        │ · 동사 활용 · 성·수        │ [읽기 시작]                   │
│        │ 단어 · 빈도 단어 · 단어 카드│                              │
└────────┴───────────────────────────┴──────────────────────────────┘
```

### 편 화면 = 리더(재생 전·재생 중 같은 화면)
```
┌────────┬──────────────────────────┬───────────────────────────────┐
│ ← 회화 │ 대화 스크립트              │ ┌─장면 컷──────────────────┐ │
│        │ 1 ● Ciao! Sono {name}. 🔊 │ │ [점토풍 컷 16:9]          │ │
│        │   챠오! 쏘노 …            │ │ 말풍선: Un caffè, per…    │ │
│        │   안녕! 나는 …야.          │ └──────────────────────────┘ │
│        │ 2 ● Un caffè, per favore. │ 캡션: Un caffè, per favore.    │
│        │   (현재 턴 · 올리브 테두리)│        •남단                   │
│        │ 3 ● …                     │ ┌ 동사: prendere ───────────┐ │
│        │                           │ │ io prendo  tu prendi       │ │
│        │                           │ │ lui/lei ▶prende◀ noi …     │ │
│        │                           │ └──────────────────────────┘ │
├────────┴──────────────────────────┴───────────────────────────────┤
│ ▶  ───●──────── 3/8   0.8× 1.0×   [Italiano 고정][독음][한국어]   │
└───────────────────────────────────────────────────────────────────┘
```
- 동사 활용 표: 캡션이나 스크립트의 동사를 누르면 컷 아래에 펼침(다시 누르면 닫힘). 현재 인칭 올리브 강조, 🔊 로 여섯 형태 듣기.
- 성·수 점: 캡션의 명사·형용사 밑 작은 점 — 남성 단수 남색, 여성 단수 테라코타, 남성 복수 남색 두 점, 여성 복수 테라코타 두 점. 점을 누르면 「il caffè → i caffè」 한 줄. 자막 칩에 [성·수] 를 하나 더 두어 끄고 켤 수 있게.

### 폰·좁은 칸
```
┌─────────────────────────┐
│ [장면 컷 44%]            │
│ 말풍선                   │
├─────────────────────────┤
│ 캡션 + 성·수 점          │
│ 대화 스크립트(스크롤)     │
├─────────────────────────┤
│ ▶ ──●── 0.8× [자막칩]    │
└─────────────────────────┘
```
동사 표는 폰에서 아래 시트로 올라온다.

### 「나」 탭 성과
```
이번 주 한 줄  ·  커버율 링("내가 아는 단어로 일상 이탈리아어의 약 N%")
절벽 마일스톤 R1 225 · R2 329 · R3 761 · R4 2,069
동사 활용 맞힘(인칭별 막대 6개)  ·  주간 점  ·  주제별 진행 격자
```
센다 = 편 완주 · 핵심 표현 맞음 · 동사 활용 맞힘 · 커버율 / 안 센다 = 앱 오픈 · 스트릭 · 포인트 · 순위.

## 4. 네비게이션
레일(배우기·복습·탐색·나) → 배우기: 회화(주제 → 편 → 리더) · 기초(소리 배우기 · 동사 활용 · 성·수) · 단어 · 빈도 단어 · 단어 카드 / 리더 → 그림 카드 · 동사 표 · 성·수 한 줄 / 프로필: 학습자 이름·성별 · 계정 · 앱 업데이트(Android)/TestFlight 안내(iOS).

## 5. 모션
컷 전환 400ms 페이드, 동사 표 펼침 200ms, 편 끝 0.8초(확대 1.05 + 올리브 오버레이, 폭죽 없음).

## 6. 지금 데이터로 되는 것 / 나중
- 지금: 리더·스크립트·독음·자막 칩·오늘의 컷 자리(컷 없으면 단어 그림·이모지 카드)·성과 데스크.
- 나중(데이터가 생기면): 동사 표는 동사 활용 데이터가 들어온 뒤 켜고, 성·수 점은 단어마다 성·수 표시가 생긴 뒤 켠다. 그 전에는 칸과 칩을 숨긴다. 콘텐츠는 이번에 만들지 않는다.

## 7. Grok 글 시안(sian_it_grok_01.md)에서 더한 것 — 2026-11-03 사용자 통과
구조는 위 it-01 그대로 두고 아래 세 가지만 더한다. 셋 다 데이터가 생길 때 켠다(그 전엔 숨김).
1. **동사 표 기본 접힘**: 현재 대사에 동사가 있을 때만 머리줄(「prendere」)이 보이고, 누르면 여섯 인칭 표가 펼쳐진다(200ms). 동사·활용 데이터가 없으면 칸 자체를 숨긴다.
2. **발음 표시**: 자막 칩 「독음」을 켰을 때만 스크립트 줄에 이중자음(pala/palla)·강세 위치를 작게 표시한다.
3. **「나」 탭 구간별 커버율**: 커버율 링 아래 「R1 n% · R2 n% · R3 n% · R4 n%」 한 줄(기기에서 계산).
가져오지 않은 것: 아이패드 홈의 하단 탭(넓은 화면은 레일 유지), 데이터 없을 때 빈 성·수 점 자리(칩으로 켜고 끔 유지), 서버 커버율 계산.
