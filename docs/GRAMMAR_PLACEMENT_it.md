## 결정할 것

1. **반과거(era·c'era·ero)를 언제부터?**
   - A) R0 부터 era·eri·c'era 만 굳은 말처럼 허용하고, 반과거 체계는 R4 **(추천 — 「Era qui」「Dov'eri?」 없이 회화가 부자연스럽다)**
   - B) R4 전에는 쓰지 않는다(R0~R2 초안 15턴쯤 고침)
2. **결합 대명사 통문장을 앞에 둘지?**
   - A) 「non ce l'ho」「me lo dai?」 같은 몇 개만 R2 채팅에 통문장으로 **(추천)**
   - B) R4 전에는 전혀 쓰지 않는다
3. **관사 결합 전치사 범위**
   - A) R1 은 단수 6개(al·alla·del·della·nel·sul), 복수형은 R3 **(추천)**
   - B) R1 에서 전부
4. **존댓말 Lei**(앞서 알림과 같은 건)
   - A) 결정대로 R3 부터
   - B) Lei 는 3인칭 단수 형태라 R1 가게 장면부터 허용

## 사용자 결정(2026-11-08)

1. 반과거: **R0 부터 era·eri·c'era 만 굳은 말로 허용**, 반과거 문법은 R4.
2. 결합 대명사: **R2 채팅에 non ce l'ho·me lo dai? 같은 몇 개만 통문장**, 체계는 R4.
3. 관사 결합 전치사: **R1 은 단수 6개(al·alla·del·della·nel·sul)**, 복수형은 R3.
