# 음성 품질 검사 — 이탈리아어앱

기준은 일본어앱 `docs/DIALOGUE_AUDIO.md` §5(품질 기준)를 따른다. 검사 코드 `tools/tts/qa.py`, 참고 음성 검사 `tools/tts/run_trial.py` `ref_bad()`.

## §5 잡음 바닥 — 측정 방식 바로잡음 (2026-11-24, uk 승인)

- **기준값은 그대로**: 조각 ≤ -55dB, 참고 음성 ≤ -60dB.
- **측정만 바로잡음**: 바닥 = **말 아닌 프레임만**의 RMS.
  - 말 아닌 프레임: 20ms 프레임이 -40dB 아래로 0.3초 이상 이어진 구간. 앞뒤 60ms 는 버린다(말끝 잦아듦).
  - 말 아닌 구간이 합쳐 150ms 미만이면 「판정 불가 = 통과」. `floor()` 가 None 을 돌려주고 qa.json 에 기록만 남는다.
  - 예전 방식(전 프레임 하위 10%)은 `floor_old()` 로 남김(비교용).
- **바꾼 까닭**: 1.4~3초 조각은 앞뒤 무음이 거의 없다(말 길이 ≈ 전체 길이). 그래서 하위 10% 가 말소리 자체에 걸렸다.
  - 11-24 회화 65편 975조각 가운데 285개가 잡음 미달로 나왔는데, 표본 12개를 받아써 보니 전부 정확했다.
  - 참고 음성은 110개 중 88개가 미달로 나왔다.
- **처음 시도한 방식은 버림**: 「-40dB 아래 60ms 이상」만으로 재면 말끝이 섞였다. 예전 통과 10개 중 9개가 미달로 뒤집혔다.
