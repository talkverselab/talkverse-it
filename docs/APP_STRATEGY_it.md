## 0. 한 줄 요약

**레벨 = 문법 단계(0~5)로 회화를 다시 묶고, 단어 메뉴의 R1~R5(절벽 61/91/211/661, 상한 2,000)는 어휘 상한으로만 쓴다** — 단수·반말로 골격을 완성한 뒤(레벨 1·2) 복수·Lei 를 갈아끼우고(레벨 3), 핵심 1 : 변형 9 의 뺑뺑이 카드와 성·수·인칭 태그, 남/여 두 판, 라임 직후 페이월을 앱에 넣는다.

- 선별 가중치: 레벨 1·4 = 빈도 20 · 활용 시연 35 · 양태 15 · 시제 10 · 단순성 15 / 레벨 2·5 = 빈도 50(A-보).

## 2. 앱 구축 순서

각 단계 = 바꾸는 것 / 지금 할 수 있는 것 / 사용자를 기다리는 것. 순서는 A12 와 맞춘다(콘텐츠는 ①~⑥, 앱은 콘텐츠보다 한 걸음 앞서 그릇만 만든다).

### 단계 1. 편 JSON 스키마 확장 (코드 없이 데이터 규격만)
- 바꾸는 것: 편 메타에 `level`(0~5 정수, 폴더 R 숫자와 같음 — B14)·`stage`(레벨 안 골격 묶음 번호)·`kind` 에 `core`/`variant` 추가, 변형 카드에는 `core_of`(핵심 문장 id). 턴에 `morph_tags[]`(A8), `it_f`·`rd_f`·`ko_f`(A9 — 대상어 칸 이름이 `it` 이므로 `tl_f` 대신 `it_f`), `segs`/`segs_f`(B11). `assets/data/dialogues/_meta.json` 의 `levels{}` 를 6개 레벨 이름으로 채움.
- 지금: 규격을 `docs/DIALOGUE_RULES_it.md` 에 한 절로 적고 `tools/check_dialogues.py` 가 새 칸을 검사하게 할 준비(값은 비워 둠).
- 기다림: 콘텐츠 동결 해제(A12 ①~②, 첫 산출물 = 레벨 1 어휘표 CSV + 코어 40).

### 단계 2. 로더 — `dialogue_service.dart` 가 R*/ 폴더를 읽게
- 현재: `L1.json`(옛 5편×8턴)만 읽고 `region` 에 `L1` 을 넣음. `levelKo` 는 L1·R0~R4 의 옛 이름(왕초보…최상급).
- 바꾸는 것: ① Flutter 는 `assets/data/dialogues/` 선언으로 **하위 폴더를 포함하지 않음** → 도구가 `assets/data/dialogues/index.json`(편 경로·레벨·주제·turns 수·draft 여부)을 생성하고 pubspec 에 `R0/life/` 식 폴더를 추가(또는 AssetManifest 로 열거). ② `Dialogue` 에 `level`·`stage`·`kind`·`coreOf` 칸, `DialogueTurn` 에 `itF/rdF/koF`·`morphTags`. ③ `levelKo` → 6개 레벨 이름(0 도구획득 … 5 어휘 완주), `region` 은 레벨 문자열로 통일. ④ `draft: true` 편은 **릴리스 빌드에서 숨김**(지금 5편은 통과 전).
- 기다림: 없음(그릇). 단 L1 과 R* 를 동시에 보일지(옛 5편 유지 여부)는 §4 결정 6.

### 단계 3. 회화 홈·리더 — 레벨 → 묶음 → 편
- 바꾸는 것: `dialogue_screen.dart` 홈을 「레벨 카드 6개 → 골격 묶음(stage) → 편」으로. 리더(시안 it-01)는 그대로 쓰고, 턴 캡션(`HintText`, 지금 숨김)을 `morph_tags` 로 켠다 — 이름은 「격 자막」이 아니라 **「성·수·인칭 자막」**(§3 항목 1). 채팅 편은 `ui: bubble`·`at`·`read` 표시(B2) — 리더에 말풍선 모드 추가.
- 기다림: 레벨 1 핵심 50 통과 전엔 묶음 카드가 비어 보임 → 통과 전까지는 레벨 카드만 보이게.

### 단계 4. 변형 카드(뺑뺑이) 화면
- 바꾸는 것: 핵심 1 : 변형 9. `sentence_flashcard_screen.dart`(지금 DB `turns` + `user_progress`)를 `kind: variant` 턴을 읽는 쪽으로 넓히거나 새 화면 「말 조각」(A8 UX 시안 01) — 문장 안에서 바뀐 조각(관사·어미·대명사)만 색으로 드러내는 카드. 데이터는 `morph_tags` 가 원천.
- 기다림: A12 ④(변형 선별 스크립트 + Claude 정제 + 태깅 통과) 뒤에야 내용이 생김. 화면은 샘플 10장으로 먼저 만들 수 있으나 **샘플도 콘텐츠** → 동결 해제 뒤.

### 단계 5. morph_tags 파이프라인 (A8)
- 바꾸는 것: `tools/morph_tag_it.py` — spaCy `it_core_news_lg`(M6 미설치) 로 토큰별 Gender·Number·Person·Tense·Mood·VerbForm·PronType 을 뽑고, 턴 `lemmas` 와 맞춰 `morph_tags` 에 쓴다 → Claude 검수(틀린 곳 `morph_manual: true`). 검사기에 「레벨 1·2 에 복수 인칭·Lei 금지」(A3·A4) 규칙 추가 — 지금 `CASUAL={R0,R1,R2}` 가 그 자리.
- 지금: 설치·시험 가능(기존 5편으로 돌려 보기 — 태그 추가는 편 JSON 을 바꾸므로 **읽기 전용 리포트만**).
- 기다림: 편 JSON 에 쓰는 것은 동결 해제 뒤.

### 단계 6. 성별판 (A9)
- 바꾸는 것: 리더·카드·말하기 연습이 학습자(A) 턴과 학습자를 부르는 턴에서 `LearnerPrefs.gender` 로 `it_f/rd_f/ko_f` 를 고름. 검사기의 「학습자 성별이 드러나는 말」 경고를 「`it_f` 없으면 오류」로 바꿈. 음성 계획(`data/tts/PLAN_GUIDE.md` 의 `m`·`f`)은 이미 두 판 구조.
- 기다림: 지금 5편은 성별 어미를 피해 `_f` 줄이 없음. 앞으로 쓰는 편부터 적용(DIALOGUE_RULES §1 A9).

### 단계 7. 음성 매니페스트
- 현재: `data/tts/audio_it.json` 에 편별 턴·`voice m/f`·`key audio/it/<편>/NN_m.mp4`·`sha1`·`ms`(5편, R2 만 완료). 앱 `assets/data/audio_manifest.json` 은 `{"words":{}}` 빈 값, `AudioService` 가 이걸 읽음.
- 바꾸는 것: 도구가 `audio_it.json` → 앱 매니페스트(`dialogues` 절) 로 변환, 재생은 `ContentSync`(그림과 같은 `auth.talkverse.uk` 경로) 로 내려받아 파일 재생. 턴 재생 버튼은 학습자 성별에 따라 m/f 키 선택.
- 기다림: **사용자 청취 판정**(HANDOFF: 품질 미달 47/96, 참고 음성 40/46 — `qa.floor` 수치는 미확인). 판정 전엔 매니페스트에 넣지 않음.
