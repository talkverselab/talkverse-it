# Grok 재작성 프롬프트 — 이탈리아어 (2026-11-08, 중국어·독일어앱 틀을 옮김)

흐름: Claude 초안(JSON) → 이 틀로 Grok 재작성(편마다 새 대화방, 「전문가」 모델) → 세션 리뷰(그대로 쓰지 않는다: 깎인 문장부호 복구·직원 반말 → Lei·논리 깨진 줄·지워진 심쿵 줄·레벨 규칙 어긴 줄) → JSON 반영 → `tools/check_dialogues.py --fix-rd` → 사용자 리뷰 → DB. 요청문은 `tools/rewrite_request.py <편.json>...` 가 아래 틀로 만든다(`data/review/grok/<편id>_prompt.md`). Grok 은 주간 한도로 11-10 뒤, 샘플 1~2편 → 사용자 통과 → 본작업.

 ③ 심쿵: 설레는 한 줄(마음을 들키는 말·말끝 흐리기·여운) — 연애 편은 반드시, 다른 편도 가능하면. 여성 인물이 먼저 훅 들어오는 쪽으로
지킬 것: ⑴ 턴 수 {n}·화자 순서 그대로 ⑵ 변수 {name} 그대로 ⑶ {grammar} ⑷ 한 턴 {words}단어 안쪽, 1~2문장 ⑸ 암기하고 싶어지는 짧고 리듬 있는 한 줄 하나 ⑹ 실존 인물·작품·브랜드 이름 금지, 성적 묘사 금지(12+) ⑺ **모든 줄을 새로 쓸 것** — 초안 문장을 그대로 두는 「유지」 금지. 뜻은 살리되 말은 당신 것으로. ⑻ 숫자는 글자로(quindici). ⑼ 학습자(A)는 남녀 모두 쓴다 — 학습자의 성별이 어미에 드러나는 턴(sono stanco/stanca, sei pronto/pronta 등)은 남성판 줄 바로 아래에 `번호F 화자: …` 로 여성 학습자판 줄을 하나 더 쓴다.
